# 🎓 University Management System

A desktop-based University Management System developed using Java and MySQL to simplify and organize university administration.

## 📌 About the Project

The University Management System is designed to manage academic and administrative information through a Java-based application connected to a MySQL database. It provides a centralized way to store and retrieve university-related records.

## ✨ Features

- 🔐 User login and authentication
- 👨‍🎓 Student information management
- 👨‍🏫 Teacher information management
- 📝 Examination and marks management
- 📅 Attendance management
- 💰 Fee management
- 🗄️ MySQL database integration

## 🚀 Getting Started

### Prerequisites

Install the following before running the application:

- Java Development Kit (JDK)
- MySQL Server
- Eclipse IDE or another compatible Java IDE
- Required project JAR dependencies

### Installation and Setup

1. Clone the repository:

   ```bash
   git clone https://github.com/sairajcodes/University-Management-System.git
   ```

2. Open Eclipse and import the project using **File → Import → Existing Projects into Workspace**.

3. Start MySQL Server.

4. Create the database and import the provided SQL file, `ums.sql`, using MySQL Workbench or the MySQL command line.

5. Check the database connection settings in the project and update the database username, password, and database name as required.

6. Ensure all required JAR dependencies are added to the project's build path.

7. Locate the application's main class and run it as a Java application.

## 🗄️ Database Setup

The repository includes `ums.sql`, which can be used to initialize the database.

Review the SQL file before importing it, and ensure the database connection configuration in the application matches your local MySQL setup.
